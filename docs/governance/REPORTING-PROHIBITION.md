# Reporting Prohibition — INFINYX

**Effective date:** 2026-11-24  
**Authority:** Explicit project-owner instruction in the active project conversation  
**Status:** Active

## Directive

Reporting is prohibited for the INFINYX project until the project owner explicitly revokes or replaces this instruction.

The prohibition includes creating or publishing:
- progress reports or status updates;
- completion or readiness reports;
- periodic or ad hoc project summaries presented as reports;
- reporting documents, dashboards, or equivalent status artifacts.

## Permitted work

This directive does not suspend authorized engineering work. Code changes, tests, defect fixes, and necessary technical maintenance may continue within the project's existing governance constraints.

A concise operational response strictly necessary to communicate the result of an explicitly requested technical action is not a project report. Do not turn such a response into a progress narrative or status document.

## Governance boundaries

This directive does not grant permission to merge pull requests, create releases, deploy, activate the Agent, or grant Phase 0. Existing project governance restrictions remain in force. In particular, PR #60 and PR #61 must remain Draft and unmerged, Agent must remain OFF, and Phase 0 remains NOT GRANTED.

## Change control

Only an explicit instruction from the project owner may revoke or amend this prohibition. Until then, treat it as active and do not create reporting artifacts.
